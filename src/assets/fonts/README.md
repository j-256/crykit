# Menu font

Pixel Operator Regular is by Jayvee Enaguas (HarvettFox96), released as version 2018.10.04-1 under CC0 1.0. The source is the author's [Pixel Operator download](https://www.dafont.com/pixel-operator.font); the distributed [license](../../../public/pixel-operator-CC0.txt) accompanies the app.

The bundled WOFF2 is a compressed copy of `PixelOperator.ttf` with its glyphs and metadata preserved. The privacy check recognizes its reviewed SHA-256 digest instead of accepting arbitrary font binaries. Font updates require reviewing the source, license, and bytes before updating that digest.

The font uses a 16-pixel em grid. Large headings use multiples of that grid at the default browser text size; compact navigation uses a smaller fixed size to preserve room for complete labels. Browser zoom and user font-size preferences remain available. Small section headings use system text instead of shrinking the pixel face. This font is a visual substitute; its use does not imply that it is Crystal Project's original typeface.
