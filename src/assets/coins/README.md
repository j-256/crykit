# Currency icons

The gold, silver, and copper PNGs are isolated Crystal Project coin artwork from maintainer-supplied game screenshot crops. The crops contain only the coin symbols, with no personal records or interface text. Their original RGB pixels and dimensions are preserved; hand-defined alpha masks remove the surrounding background. The source JPEGs and full screenshots are not bundled.

Crystal Project is by Andrew Willman. This game artwork belongs to its respective creators and rights holders and is not covered by the application's AGPL license. See [game artwork credits](../../../NOTICE.md#game-artwork). These screenshot-derived icons are separate from the community wiki sprite manifest and are bundled locally for offline use.
