# Built-in starter catalog sources

Crystal Companion ships a static, names-only starter catalog so a blank local profile can search and select useful Crystal Project references without importing a file or making a runtime network request. The catalog stores public names, app-defined stable identities, entity kinds, and source links. It does not bundle descriptions, formulas, costs, stats, locations, unlock conditions, inventory, observations, or character progress.

Coverage is deliberately partial. It includes item and equipment labels represented as ordinary game records by the public Archipelago world, its base class and Monster Magic names, Equipment Expansion item labels, the four Mod Pack 2 classes named by the publisher, and a community-documented selection of active abilities, passives, and class innates. Archipelago-only progression wrappers, region passes, events, victory markers, and traps are excluded. The catalog does not claim complete Nintendo Switch coverage, parity with a particular game revision, or complete coverage of either official mod pack. Every mechanics-bearing field remains unknown.

The base item, equipment, class, and Monster Magic labels come from the public [Crystal Project Archipelago world](https://github.com/Emerassi/CrystalProjectAPWorld), principally its [item table](https://github.com/Emerassi/CrystalProjectAPWorld/blob/main/worlds/crystal_project/items.py), [class constants](https://github.com/Emerassi/CrystalProjectAPWorld/blob/main/worlds/crystal_project/constants/jobs.py), and [Scholar ability constants](https://github.com/Emerassi/CrystalProjectAPWorld/blob/main/worlds/crystal_project/constants/scholar_abilities.py). That project targets a Steam Archipelago branch and does not establish Nintendo Switch compatibility. Its repository is MIT-licensed, but this catalog copies only factual labels and source links.

Equipment Expansion labels come from the [public Equipment Expansion item sheet](https://docs.google.com/spreadsheets/d/1s3kWj2DONAln5hRx7p4JyEfr71wkLIM-KC3LTA3gNks/edit#gid=0). Nintendo's [Mod Pack 2 description](https://www.nintendo.com/en-gb/DLC/Mod-Pack-2-New-Challenges-2646897.html) confirms that Equipment Expansion and the named Bloodmage, Tempest, Forcemage, and Barbarian classes are included in the Switch DLC. It does not establish that the public sheet matches the packaged Switch revision, so per-entity platform applicability remains unknown.

Ability, passive, and innate labels were checked against their public pages on the [Crystal Project community wiki](https://crystal-project.fandom.com/wiki/Classes). The catalog retains the specific public page URL on each entity. Community documentation can be incomplete or stale, and no wiki prose or mechanics are bundled.

The wiki evidence remains independently reproducible through its public MediaWiki API with redirect resolution. For example, the [Warrior page source response](https://crystal-project.fandom.com/api.php?action=parse&page=Warrior&redirects=1&prop=wikitext&format=json&formatversion=2) identifies Fighter in the innate field and marks Taunt as an ability and Grudge as a passive. The [Scholar page source response](https://crystal-project.fandom.com/api.php?action=parse&page=Scholar&redirects=1&prop=wikitext&format=json&formatversion=2) marks Infusion and Roost as Monster Magic and Learning as a passive. These public responses are evidence for names and kinds only.

The snapshot checksum uses a `builtin:sha256:` namespace over the static source map and name records. It is catalog identity metadata, not an imported source-file digest, and it does not imply that source archive bytes are retained. Updating names requires reviewing the public evidence, preserving existing entity IDs where identity is unchanged, bumping the catalog revision, and regenerating the checksum. Runtime code must continue to make no catalog network requests.
