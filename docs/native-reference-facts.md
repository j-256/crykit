# Native reference facts

The launch definition catalog is built directly from fingerprinted Crystal Project 1.6.9.0 databases and reviewed implementation facts. It does not merge wiki definitions or overlay corrections on community guide records. Native numeric identities, source fingerprints, and exact record contents determine which facts apply.

Verified native facts appear as ordinary content without routine citation markers. Uncertain values and external imported claims retain Sources controls. Suppressing a routine native citation does not discard provenance or broaden version, platform, or mod applicability. See [platform coverage](platform-coverage.md) and [catalog sources](catalog-sources.md).

| Content | Native source and behavior |
| --- | --- |
| Descriptions | The description renderer expands supported native vocabulary and display rules. Incomplete rendering retains explicit gaps rather than importing another source's explanation. |
| Equipment | Numeric equipment types and modifier tags supply categories, flat stats, and supported effects. On-hit statuses remain attached to their trigger, chance, and duration. |
| Classes and learning | Job records supply ratings, permissions, innate identities, and learn-tree coordinates. Skill references resolve by numeric family and ID within their source and mode. |
| Acquisition | Native reward, shop, recipe, drop, and steal records supply routes. Reviewed world conditions and price facts keep their own fingerprints. Missing routes do not establish unobtainability. |
| Gardening | Native seed, encounter, growth, and watering rules retain integer arithmetic and zero-reduction cases. |
| Mechanics | Standalone reviewed native entries explain supported modifier semantics and link to the native calculation reference. |
| Quintar breeding | Native rules supply pairing outcomes, race minimums, readiness, food, nursery capacity, and hatching. A compact attributed guide supplies route order and capture directions, while personal completion records remain separate. |
| Artwork | Exact native database and texture bindings supply local images. Unsupported bindings remain explicit gaps with readable fallback content. |

Useful directions and route choices can be retained as small, attributed supplements to native facts. These do not reintroduce the full community catalogs or override native mechanics.

No projection updates inventory, character learning, recorded progress, or a saved Game Setup. Imported sources and personal definitions remain distinct. Source names and equal display names cannot establish equivalent identities, verified mechanics, or platform parity.

The native-only prelaunch revision intentionally does not resolve retired bundled-catalog references through aliases or historical community records. Existing personal records remain stored. Complete source bodies embedded in a user's backup are handled as imported dependencies, without becoming part of the launch bundle.
